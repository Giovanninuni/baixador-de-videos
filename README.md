# Baixador

Baixa vídeo (MP4) ou só áudio (MP3) do YouTube, X/Twitter, Instagram, TikTok e centenas de outros sites.

## Usar
Duplo clique no atalho "Baixador de Vídeos" na Área de Trabalho (ou em `baixador.pyw`) → cole o(s) link(s) → escolha Vídeo ou Áudio → **Baixar**.
Os arquivos vão para a pasta Downloads (dá pra trocar na janela).

## Parou de funcionar em algum site?
Os sites mudam de vez em quando. Rode `atualizar.bat` e tente de novo.

## Instagram privado / stories
Escolha seu navegador em "Usar login do navegador" (você precisa estar logado nele).
Se der erro com o Chrome, feche o Chrome e tente de novo, ou use o Firefox.
