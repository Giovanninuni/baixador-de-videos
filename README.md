# Baixador

Baixa vídeo (MP4) ou só áudio (MP3) do YouTube, X/Twitter, Instagram, TikTok e centenas de outros sites.

## Usar
Duplo clique no atalho "Baixador de Vídeos" na Área de Trabalho (ou em `baixador.pyw`) → cole o(s) link(s) → escolha Vídeo ou Áudio → **Baixar**.
Os arquivos vão para a pasta Downloads (dá pra trocar na janela).

## Cortar áudio
Aba **Cortar áudio** → *Abrir arquivo…* (áudio ou vídeo).

- **Andar pelo áudio:** clique na onda (cursor amarelo) · `←`/`→` 1 s · `Shift` 5 s · `Ctrl` 0,1 s · `Home`/`End` vão para o início/fim do corte
- **Tocar/pausar:** `Espaço` (toca a partir do cursor) · *Ouvir trecho* toca só o corte
- **Marcar o corte:** arraste as barras brancas, ou `I` / `O` marcam início / fim onde está o cursor, ou digite o tempo (ex.: `1:23.5`)
- **Volume final:** níveis fixos em LUFS (-23, -18, -14, -11, -8). O arquivo sai *naquele* volume, não importa como estava — com limitador para não distorcer
- **Fade:** suaviza o começo e o fim

Depois de baixar algo, o botão **Cortar último ✂** já abre o arquivo no editor.

## Parou de funcionar em algum site?
Os sites mudam de vez em quando. Rode `atualizar.bat` e tente de novo.

## Instagram privado / stories
Escolha seu navegador em "Usar login do navegador" (você precisa estar logado nele).
Se der erro com o Chrome, feche o Chrome e tente de novo, ou use o Firefox.
